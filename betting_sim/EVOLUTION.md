# 진화 규칙 (betting_sim)

목표: 가상 1,000만원 → 1억. 실제 돈·계정·로그인 없음. 규칙은 고정하지 않고 데이터로 계속 바꾼다.

## 주기
| 주기 | 할 일 |
|---|---|
| 매일 (영국 08:47) | 정산 → 픽 → 장부 커밋 (paper_trade.py run) |
| 하루 4회 (KST 09/15/21/03) | Polymarket 정산 → 픽 → 커밋 (pm_trade.py run) |
| 매주 월요일 (영국 10:23) | 진화 리뷰: 성적 분석, 새 데이터 반영, 규칙 변경 제안/적용, 필요한 API·데이터 요청 |

## 규칙을 바꾸는 조건 (과적합 방지 안전장치)
1. **새 규칙은 반드시 '안 본 데이터'로 검증**: 과거 데이터는 학습/검증으로 나누고, 검증구간에서도 바카라(-1.06%)보다 나아야 채택.
2. **실전 기록(모의투자)으로 판단은 표본 100판 이상부터.** 그 전에는 몇 판 결과로 규칙을 바꾸지 않는다.
3. **한 번에 하나만 바꾼다** → 무엇이 효과였는지 알 수 있게.
4. **모든 변경은 버전으로 기록** (아래 변경 이력). 이전 버전도 '그림자 트랙'으로 계속 기록해 비교할 수 있게.
5. 정보 추가(새 리그, 새 데이터, 새 API)는 언제든 가능하지만, 실전 규칙 반영은 1~4를 통과해야 함.

## 정보 확장 후보 (요청 대기)
| 우선 | 무엇 | 왜 | 사용자에게 필요한 것 |
|---|---|---|---|
| 1 | The Odds API (무료 요금제) | 실시간 bet365 + 여러 업체 배당 → 가치 판정, 배당 반영 지연 탐지, 미국 종목/테니스 실시간 | 이메일 가입 후 키 (보안 입력창으로) |
| 2 | API-Football (무료 요금제) | 선발 라인업·부상·결장 → 시장보다 빠른 정보 | 가입 후 키 |
| 3 | tennis-data.co.uk 엑셀 | 테니스 과거 배당(데이터센터 IP 차단이라 직접 못 받음) | 브라우저로 받아 업로드 |
| 4 | KBO/KBL/K리그 과거 배당 | 국내 종목 분석 | 보유 파일 있으면 업로드 |

## 하지 않는 것
로그인·가입·입금, 접근 차단 우회(VPN/프록시/봇차단 회피), 약관상 수집 금지 사이트 크롤링(BetExplorer 등), robots.txt가 거부한 사이트.
