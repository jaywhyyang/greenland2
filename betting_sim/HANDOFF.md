# 인수인계: 스포츠 베팅 모의 시뮬레이션 (betting_sim)

저장소 `jaywhyyang/greenland2`, 브랜치 `claude/sports-betting-edge-validation-wxh36b`, 폴더 `betting_sim/`.
이 문서만 읽고 이어서 운영할 수 있게 쓴다. 상세 변경 이력은 `EVOLUTION.md`, 과거 분석 결과는 `RESULTS.md`.

## 0. 절대 규칙 (사용자 지시, 최우선)
- **가상 돈만.** 실제 입금·베팅·거래 금지.
- **샘플사이트(luckwiz.com 등) 로그인 금지, 회원가입·가입 시도 금지.** 사용자는 불법을 가장 경계함.
- 접속 차단·봇 차단을 우회하지 않음(VPN, 프록시, 차단 회피 금지). robots.txt나 약관이 막은 자동 수집은 하지 않음.
- 샘플사이트 배당은 **사용자가 시킬 때 한 번씩, 로그인 없이 공개 화면만** Chrome으로 읽는다. 예약·반복 자동 수집을 만들지 않는다.
- 보고는 한국어로, 짧고 자주.

## 1. 목표와 방식
- 가상 자금 1,000만원. 각 베팅법은 **3배(3,000만)** 에 닿으면 원금 1,000만을 따로 떼어 놓고 이익만으로 계속.
- **한 테이블**: 동시에 한 판만. 결과가 확정돼야 다음 판(바카라 한 테이블처럼). 하루 최소 1~2판 목표.
- 한 판 = **2폴더 묶음**: 다리 배당 1.30~1.55 두 개, 묶음 배당 1.90~2.20(2.0 근처, 바카라 느낌).
  - (table7~) 이 범위는 **샘플사이트 배당 기준**으로 적용한다 (사용자: "저 사이트가 현실").
- 종목 무관 "가장 좋은 픽" 하나.
- 사용자 요청 보고 순서: **① 후보 전체와 엣지 → ② 점수 상위 조합 → ③ 그 다음 최종 픽.**

## 2. 픽 고르는 법 (one_table.py, table3/5/7 규칙)
1. Polymarket 공개 API(gamma-api.polymarket.com, 조회 전용)로 마감 8일 범위의 승패 시장을 12시간 단위로 나눠 전부 조회(`pm_trade.candidates`). 호가차 6센트 이하.
2. 24시간 안에 시작하는 다리마다 **공정확률 p** 추정:
   - ① The Odds API(`odds_ref.py`, 키 환경변수 `ODDS_API_KEY`, 하루 15크레딧, 4시간 캐시) 여러 업체 배당에서 마진을 비례 제거한 중앙값 = "시장합의"
   - ② 없으면 Polymarket 중간가
   - 축구 "Will X win?"은 3지선다(무승부 포함)로 매칭.
3. 다리 엣지 = Polymarket 배당 × p − 1. 거래량 $1k 미만이면 −1% 감점.
4. **샘플사이트 환산 배당** = 1 / (p × (1+마진)), 소수 둘째 자리 내림.
   - 마진: 축구 승무패 4.0%, 그 외 2지선다 6.4%. 사용자 캡처 2장으로 잰 값(아래 6절).
   - **실제 사이트 배당 스냅숏이 있으면 그것을 우선 쓰는 것이 다음 할 일**(7절).
5. 사이트 배당 1.30~1.55인 다리만 남기고, 사이트 묶음 1.90~2.20인 조합 중 **점수 = (1+e1)(1+e2) − 1 − 0.05% × (마지막 경기까지 시간)** 최대인 것을 고른다.
6. 같은 경기 두 다리 금지. 이미 쓴 시장 재사용 금지.

## 3. 베팅법 (같은 픽에 동시 기록, 각 1,000만 시작)

## 4. 정산·기록
- 결과: Polymarket 시장이 closed이고 가격이 0.99 이상이거나, UMA 결과가 proposed/resolved이고 가격이 0.995 이상이면 확정. 반반 종료 또는 10일 경과 시 무효(V).
- **CLV**(`clv.py`): 경기 시작 직전 Polymarket 시세(clob.polymarket.com/prices-history, 공개)로 close_p, clv = 산 배당 × close_p − 1. 실력 판정은 적중보다 CLV로.
- 장부: `paper_table/legs.csv`(다리별), `paper_table/state.json`(베팅법별 자금·칸), `paper_table/candidates_latest.csv`(마지막 후보 전체).
- 경기 시작 전 기록 증빙을 위해 **장부 변경은 바로 커밋 후 같은 브랜치에 push**.
- 옛 장부 `paper_pm/`(난사 시절, 8승 8패)은 종료. `paper/`(축구 bet365) 중단.

## 5. 명령
```
cd betting_sim
python3 one_table.py run     # 정산 → (진행 중인 판이 없을 때만) 후보·엣지·상위 조합 표시 → 픽 → 현황 + CLV
python3 one_table.py cands   # 기록 없이 지금 후보만
python3 one_table.py status  # 현황
python3 clv.py               # 두 장부 CLV 요약
```
- 2시간마다 스캔(run → 변경 있으면 커밋·push → 짧은 한국어 보고).
  - 새 픽이면 ①후보 요약(다리 수, 시장합의 수, 엣지 상위 5~8개 표) ②상위 3조합 ③최종 픽(경기·배당·묶음·메인 베팅액), 메인 자금·3배 진행률, 비교 베팅법 한 줄.
  - 아무 일 없으면 한 줄.
- 진화 규칙(EVOLUTION.md): 실전 100판 전에는 결과 몇 판으로 규칙을 바꾸지 않는다. 바꿀 땐 한 번에 하나, 버전 기록. 매주 월요일 리뷰.

## 6. 지금까지 알게 된 것 (요약)
- 어떤 종목도 무조건적인 플러스 엣지는 검증되지 않음. Polymarket은 시장합의 대비 공정가~−1%. 베팅법은 엣지를 만들지 못하고 결과 분포만 바꾼다.
- 개별 경기 적중은 시장 예상과 일치(35개 중 24개, 69%). 2폴더는 약 49% 동전 던지기. 진 판 대부분은 한 다리 차이.
- CLV 평균 약 −3.4%. 큰 손실은 저유동성 e스포츠·하위 테니스에서 우리가 산 뒤 가격이 뒤집힌 경우 → 다음 주간 리뷰 1순위 후보: 저유동성 e스포츠 제외.
- 샘플사이트 마진(캡처):
  - 2026-11-21 알카라스-셸튼: 승패 1.22/4.10 → 6.4%, 게임 핸디 1.50/2.38 → 8.7%, 오버언더 22.5 1.73/1.96 → 8.8%
  - 라치오-레체 승무패 1.53/4.40/6.30 → **4.0%**, 무승부 적특 6.4%, 오버언더 2.5 6.4%
- 사이트 2폴더(승패) 기대값 약 −12%로 바카라(−1.06%)의 약 11배 불리. 유일한 틈은 **사이트가 시세 변화를 늦게 따라올 때**: 라치오는 시장이 68%→64.5%로 내려갔는데 사이트는 1.53을 유지.
